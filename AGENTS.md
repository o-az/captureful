## Development

### NOTE!

- For JavaScript, type the code with JSDoc
- do not use abbreviations. For example, instead of `el`, `ctx`, `evt`, `e`, `btn`, use `element`, `context`, `event`, `error`, `button`
- Only define types inline, and never at the top of the file
- Never typecast unless the types have a verified bug
- Never touch files in **/\_/** directories (your scratch notes)
- No "temporary patches" or backward-compatibility shims unless you ask for them
- No hedging words like "likely" or "probably": verify the answer or say it can't be verified
